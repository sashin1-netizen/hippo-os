# Hippo OS audio provenance

Hippo OS is offline-first. Nature ambience and selected real-animal recordings are fetched at build time from Wikimedia Commons and bundled into the APK. Every fetched recording is checksum-pinned by the build. Hippo breathing, footsteps, chewing, splash, mud, UI effects and fallback animal cues are generated by Hippo OS from original synthesis code.

The dog recording is a generic domestic-dog bark, not represented as a Shar-Pei-specific field recording. Bao uses it sparingly for contextual dog vocal behaviour. The pig recording is a real farm pig grunt. Hippo OS varies gain/pitch and positions these recordings at the animals in 3D; it does not present either recording as a complete species vocal library.

Pig attribution: **erdie**, `Pig grunt - Erdie.ogg`, Creative Commons Attribution 3.0 Unported. Hippo OS uses the recording as a contextual in-app sound and applies runtime pitch/gain/spatial processing.

The build workflow verifies each downloaded file against the recorded source SHA-1 before Godot imports it. If foreground animal recordings are unavailable in a local development checkout, `scripts/companion_audio.gd` falls back to original generated cues so the project still opens and runs offline.

## Dolby / spatial-audio wording

Hippo OS uses its own Godot spatial mix and does **not** claim Dolby Atmos certification or Dolby branding. Dolby technology and trademarks require the appropriate Dolby licensing/approval. The product wording should be “immersive spatial audio” or “cinematic 3D audio” unless a future licensed Dolby implementation is completed and approved.
