# Hippo OS audio provenance

Hippo OS is offline-first. Nature ambience is fetched at build time from Wikimedia Commons and bundled into the APK. The three recordings below are either CC0 or public domain. The hippo vocalisations, breathing, footsteps, chewing, splash, mud and UI effects are generated by Hippo OS at runtime from original synthesis code in `scripts/audio_director.gd`, so no third-party animal-effect license is required for those sounds.

The build workflow verifies each downloaded file against the source SHA-1 before Godot imports it. If the recordings are unavailable in a development checkout, the app falls back to generated ambience so the project still opens and runs offline.

## Dolby / spatial-audio wording

Hippo OS uses its own Godot spatial mix and does **not** claim Dolby Atmos certification or Dolby branding. Dolby technology and trademarks require the appropriate Dolby licensing/approval. The product wording should be “immersive spatial audio” or “cinematic 3D audio” unless a future licensed Dolby implementation is completed and approved.
