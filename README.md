# Hippo OS 🦛

**A personal, offline-first virtual baby pygmy hippo companion for Android.**

> The hippo must feel like a living animal, not a menu-driven virtual pet.

## Active build path

The active Android build is **Godot 4.7.2 + GitHub Actions**, targeting **Android 16 / API 36**. The project is intentionally structured so its test APK can be built on GitHub-hosted infrastructure without requiring a local PC or a paid cloud builder.

The earlier Unreal Engine prototype remains in the repository as a preserved reference, but it is **not** the active Android build path because Unreal requires a suitable build machine with the engine installed.

## What the current Godot build contains

- original procedural 3D baby pygmy hippo companion
- persistent hippo name, bond, personality and interaction history
- personality traits that influence autonomous behaviour
- autonomous idle, wandering, approach, exploration, play, water, mud and rest routines
- direct head/body petting with different bond response
- feeding
- hunger, energy, affection, curiosity and cleanliness state
- wetness and mud-coat state with visible surface changes
- breathing, blinking, ear flicks, stride, tail and sleep motion foundation
- non-punitive offline progression
- autosave plus pause/focus/exit persistence
- invalid-save recovery fallback
- generated sanctuary with grass, pond, mud, rest area, rocks and vegetation
- orbit camera, zoom, sensitivity and reset controls
- rename flow and destructive-reset confirmation
- persisted settings for volume categories, haptics, stats visibility, reduced motion, text size and day/night lighting
- immersive spatial-audio director with 3D hippo, pond and habitat emitters
- layered forest, bird and stream ambience using checksum-verified public-domain / CC0 recordings
- original procedural hippo grunts/chuffs, breathing, chewing, footsteps, splash, mud and UI effects
- separate Master, Animal, Foley, Ambience and UI audio buses
- dynamic ambience ducking around hippo vocalisations
- EQ, compression, environmental reverb and a Master hard limiter for clean playback
- actual Master, Animal, Ambience and UI volume settings wired into the live mix
- in-repository audio provenance and licence records
- Android back handling
- Android ARM64 export
- ETC2/ASTC mobile texture import support
- Android 16 / API 36 package verification
- APK signature verification and SHA-256 output in CI
- pull-request Android build gate before changes reach `main`

## Immersive audio

Hippo OS is designed for a **cinematic 3D / immersive spatial-audio experience**. Hippo sounds follow the animal in 3D space, water is positioned at the pond, environmental layers sit around the sanctuary, and the mix dynamically makes room for close animal sounds.

The project does **not** claim Dolby Atmos certification or use Dolby branding. Dolby technology and trademarks require the appropriate licensed implementation and approval. A future licensed platform-spatial-audio integration can be added without replacing the current sound-design architecture.

The current animal voice and interaction Foley are original procedural sounds generated by Hippo OS. This keeps the build legally clean and fully offline. A future professionally recorded, legally licensed pygmy-hippo vocal/Foley pack can replace or layer over these generated sounds for a still more natural result.

## Android test build

Open **Actions → Build Android APK → Run workflow**.

GitHub automatically:

1. starts a hosted Ubuntu runner
2. installs Java 17
3. installs the Android API 36 toolchain
4. downloads Godot 4.7.2 and Android export templates
5. fetches and checksum-verifies the approved sanctuary ambience recordings
6. imports the audio and validates the Godot project headlessly
7. generates a debug signing key for test builds
8. exports `HippoOS.apk`
9. verifies package ID `com.sashin.hippoos`, target SDK 36 and APK signature
10. writes a SHA-256 checksum
11. uploads the verified build artifact
12. publishes the verified APK to GitHub Releases only for successful pushes to `main`

## Play Store release gate

The verified GitHub APK is a **test/sideload build**, not the final Google Play artifact. A Play release still requires a persistent production signing key and a release-signed **Android App Bundle (AAB)**. Those credentials must never be committed to this repository.

## Product rule

Moo Deng is behavioural inspiration only. Hippo OS uses an original virtual baby pygmy hippo and can later replace the procedural character with a premium custom 3D model without changing the underlying pet systems.

## Launch status

**Playable pre-alpha with a verified Android 16/API 36 test-build pipeline and a working immersive spatial-audio foundation.**

The project must **not** be described as fully launch-ready yet. The major remaining release-gate work is a production-quality rigged pygmy hippo model, authored animation set, a more natural professionally recorded/licensed pygmy-hippo vocal pack, final sanctuary art and water/mud effects, complete responsive-device QA, accessibility review, production signing/AAB packaging and successful on-device acceptance testing.
