# Hippo OS Asset Provenance Register

This register describes assets used by the current `release/flutter-4k-v1` production pipeline. No third-party production asset may be bundled unless its source and licence are recorded here.

## Generated production animal models

Mochi, Truffle and Bao are generated from the original JSON specifications above during CI. The release pipeline clones the model compiler at a fixed commit and compiles the three specifications into skinned/animated GLB files before Godot import. No Sketchfab or downloaded animal mesh is used in the production build.

| Tool/output | Source | Licence | Production handling |
|---|---|---|---|
| anyCreature compiler | `Ariescar/anyCreature`, pinned commit `ab5b1ce5c13e632f00f7f7cbfdb7a746e315000d` | MIT, copyright Alsomind Tech Co., Ltd. | Compiler is fetched at build time; generated GLBs are embedded into Hippo OS. Compiler source is not bundled into the Android app. |

## In-app attribution

The Flutter production shell includes a **Credits & licences** panel. It identifies the model compiler, Poly Haven visual sources, pig attribution, public-domain/CC0 dog recordings, the hippo field source, and the original Hippo OS generated audio. The CC BY pig credit is retained even though Hippo OS 1.0 is personal/private use.

## Assets explicitly not used in production

Earlier research considered third-party Sketchfab hippo, pig and Shar-Pei meshes. Those candidates were abandoned and are not part of the current production pipeline or Android package. Production animals are generated from the original Hippo OS specifications instead.

## Release rules

1. No asset with unclear licensing ships.
2. CC BY assets retain required attribution in-app and in this register.
3. NC/NonCommercial assets are not acceptable for the release package.
4. No trademarked character likeness is copied.
5. Mochi remains an original pygmy-hippo identity and is not a direct Moo Deng reproduction.
6. Visual QA and any user-facing screenshots must show the actual app experience rather than concept art.
7. Build-time downloads must be pinned by exact source URL or tool commit and must pass import/existence validation before packaging.
