## Release rules

1. No asset with unclear licensing ships.
2. CC BY assets require in-app and repository attribution.
3. NC/NonCommercial assets are not acceptable for a general public release.
4. No trademarked character likeness is to be copied.
5. The pygmy hippo must have an original identity and should not be a direct Moo Deng reproduction.
6. Store screenshots and feature graphics must show the actual app experience rather than misleading concept art.
